# Enrique Gamboa | Professional Portfolio

Welcome to the repository for my personal portfolio website. As a Data Engineer and AI Architect with over 11 years of experience designing secure, scalable data ecosystems, this site serves as a digital representation of my professional journey.


## 🚀 Overview

This project is a modern, fast, and responsive web application built to showcase my technical background, career milestones, and open-source contributions. The application is structured as a single-page application using a modern frontend stack.


## 🛠️ Tech Stack

-   **Framework:** React
    
        
-   **Language:** TypeScript
    
        
-   **Build Tool:** Vite
    
        
-   **Styling:** CSS
    
        

## 📂 Core Features & Structure

The application is built with modular components found in the `src/components/` directory:


-   **`ResumeSection.tsx`**: Highlights my professional experience, including my current role as a Senior Data Engineer at Ultragenyx and past roles at Versum Materials and Goldman Sachs\[cite: 1, 2\].
    
-   **`ProjectsSection.tsx`**: Showcases my technical projects and research, such as my first-place MIT Hackathon project, Lightning Bounties\[cite: 1, 2\].
    
-   **`GitHubSection.tsx`**: Integrates my open-source work and development activity directly into the UI.
    
-   **`Typewriter.tsx`**: A custom UI component that adds dynamic, typing-effect text to the interface.
    
        

## 💻 Getting Started

To run this project locally, follow these steps:

1.  **Clone the repository:** `git clone <repository-url>`
    
2.  **Install dependencies:** Utilize the provided `package.json` file to install the necessary packages.
        
3.  **Configure environment variables:** Copy the `.env.example` template to configure your local environment.
       
4.  **Start the development server:** Launch the server using the configuration specified in `vite.config.ts`.
